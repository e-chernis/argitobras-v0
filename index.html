CVV Dinámico

Seguridad y autenticación de pagos.

Implementé soluciones de seguridad para autenticación de pagos dinámicos en Redbee Studios. Utilicé AWS Lambda, API Gateway y Keycloak para gestionar identidades y accesos seguros, asegurando cumplimiento con estándares de seguridad financiera.

  • Fecha: Julio 2021 - Presente
  • Cliente: Redbee Studios
  • Categoría: Seguridad IT

3D Secure

Seguridad y autenticación de pagos.

Desarrollé protocolos 3D Secure para autenticación de transacciones en línea. Integré servicios de verificación de identidad con APIs externas, utilizando Terraform para IaC y Prometheus para monitoreo de rendimiento.

  • Fecha: Julio 2021 - Presente
  • Cliente: Redbee Studios
  • Categoría: Seguridad IT

Todopago

Billetera virtual.

Trabajé en la plataforma Todopago, una billetera virtual para pagos electrónicos. Gestioné despliegues en EKS, configuré pipelines CI/CD con ArgoCD y optimicé bases de datos RDS para alta disponibilidad.

  • Fecha: Julio 2021 - Presente
  • Cliente: Redbee Studios
  • Categoría: Fintech

BIMO

Billetera virtual.

Desarrollé la billetera virtual BIMO, enfocándome en seguridad y escalabilidad. Implementé monitoreo con Grafana, logging con OpenSearch y gestión de identidades con Keycloak.

  • Fecha: Julio 2021 - Presente
  • Cliente: Redbee Studios
  • Categoría: Fintech

Migración a la Nube en Balanz

Implementación de CI/CD y monitoreo.

En Balanz, lideré la migración de infraestructuras a la nube, implementando pipelines CI/CD con Jenkins y Ansible, y monitoreo con Zabbix y Prometheus para asegurar alta disponibilidad.

  • Fecha: Agosto 2019 - Julio 2021
  • Cliente: Balanz Capital Valores
  • Categoría: DevOps

Automatización en Mercadolibre

Soporte IT y scripting.

En Mercadolibre, automatizé procesos de soporte técnico con scripting en Python y PowerShell, gestioné redes y dispositivos, y optimicé inventarios con herramientas como Snipe-IT.

  • Fecha: Septiembre 2017 - Enero 2019
  • Cliente: Mercadolibre
  • Categoría: Soporte IT
